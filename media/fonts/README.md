# Fonts

- `VT323-latin.woff2`: VT323, Copyright 2011 The VT323 Project Authors.
- `JetBrainsMono-latin.woff2`: JetBrains Mono, Copyright 2020 The JetBrains Mono Project Authors.

Both are the unmodified **Latin subset** files Google Fonts serves (fonts.gstatic.com). They were taken from the original Pip mockup, which had embedded them. Characters outside Latin fall back to the system monospace font.

Both fonts are licensed under the SIL Open Font License 1.1. The full licence text for each, with its copyright line, is in `OFL.txt`. Loaded locally only (`font-src` = webview `cspSource`), never from a remote URL.
